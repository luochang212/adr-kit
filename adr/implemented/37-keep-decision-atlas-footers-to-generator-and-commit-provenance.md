# ADR: 37 Keep decision-atlas footers to generator and commit provenance

## Problem

Before this change the generated atlas footer combined the generator attribution, an explanation
that it comes from current records, the pinned commit, a project-home link and
a language-switch link. This wrapped across several lines on narrow displays.
The maintainer requested removing both navigation links and shortening the
attribution in both languages. Inspection confirmed that the local generated
English and Chinese footers carry the same information; the requested change
reduces both, rather than correcting an extra English-only sentence.

## Decision

Both generated atlas languages keep project identity, generator attribution,
and the pinned commit link. The attribution is `Generated by adr-kit` in
English and `由 adr-kit 生成` in Chinese. The redundant current-records phrase,
project-home link and language-switch link are removed from both footers.
Their unused renderer options and build inputs are removed too.

The maintainer raised and determined this presentation change to reduce mobile
wrapping. This partially replaces ADR 34's footer cross-links, while its
bilingual build and single template/translation source remain active. ADR 29's
build-time provenance and commit pinning are unchanged.

## Alternatives considered

- **Retain both footer navigation links**: rejected by the maintainer because
  the mobile footer becomes too long and wraps into too many lines.
- **Shorten the English footer alone**: rejected. The maintainer explicitly
  requested removing the links in both languages; the information is already
  equivalent in the generated markup.
- **Drop the commit attribution too**: not selected. The request removes
  navigation and redundant wording; the pinned source remains useful provenance.

## Consequences

### Verification

- Renderer tests check both languages for short attribution, the tool link and
  commit link, with no home/language links or redundant wording.
- Both generated site artifacts contain only the two provenance links in the
  footer. The unused homeHref/langHref options and build inputs are gone.
- Focused tests, typecheck, CLI/site builds and ADR validation pass.

### Trade-offs

- Footer navigation back home and between languages is no longer available.
  Both page URLs remain published; this change adds no alternate navigation.
- English attribution is naturally longer, so compact content does not promise
  identical line counts at every viewport width.
